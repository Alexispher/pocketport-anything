# Native Nintendo 3DS demonstration

The executable original libctru/citro2d example is in `../../templates/3ds-homebrew/`. It implements video setup, textured-console-free rectangular rendering, Circle Pad handling, A/START events, read-only RomFS data and orderly cleanup. Build with `make -C templates/3ds-homebrew` when devkitARM and 3DS dependencies are installed. This example is not a port of a commercial game.
