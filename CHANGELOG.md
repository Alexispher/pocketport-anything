# Changelog

## 0.2.0 — 2026-11-11

- Audited the actual public GitHub baseline: only README, MIT LICENSE and `.gitignore` were present. Retained the project's identity and license.
- Added an evidence-first Python CLI (workspace, hashes, inventory, planning, environment, build, test, report and original unified demonstration).
- Added a genuine, narrow PocketPort IR v1 parser/interpreter and C99 translator; compared generated compiled host code with reference semantics.
- Implemented an original portable C Star Catcher minigame with host runner and original 3DS citro2d frontend; linked generated scoring code with shared C game/runtime modules.
- Added portable memory budget accounting, input mapping and relative asset path guards.
- Added Pillow-based image preparation, quality profiles, explicit unsupported formats and optional real tex3ds conversion.
- Added original 3DS rendering/input/RomFS template, 24 host regression tests and a GitHub Actions host CI workflow.
- Added engineering agent instructions, a reusable skill, platform compatibility/research documentation and Zelda case study.
- No devkitARM, Azahar or real 3DS build has been claimed in this release; these dependencies were unavailable in the implementation environment.
